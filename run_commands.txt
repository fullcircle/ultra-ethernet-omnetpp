Correct Commands to Run Ultra Ethernet Simulations

  Basic Command Syntax:

  ./ultraethernet_sim_dbg -u Cmdenv -c <CONFIG_NAME> -f <INI_FILE>

  Available Make Targets:

  # Build the simulation
  make

  # Run verified working tests
  make run-working         # 2-host basic test
  make run-multi          # Multi-host tests (2, 4, 16 hosts)

  # Scale testing
  make run-64             # 64-host large scale
  make run-100            # 100-host extreme scale
  make run-massive        # 256-host massive scale
  make run-stress         # High traffic stress test

  Direct Command Examples:

  # Basic 2-host test (what we just ran)
  ./ultraethernet_sim_dbg -u Cmdenv -c General -f omnetpp.ini

  # Multi-host configurations
  ./ultraethernet_sim_dbg -u Cmdenv -c TwoHost_Direct -f working_multi_test.ini
  ./ultraethernet_sim_dbg -u Cmdenv -c MultiHost_4 -f working_multi_test.ini
  ./ultraethernet_sim_dbg -u Cmdenv -c MultiHost_16 -f working_multi_test.ini

  # Large scale tests
  ./ultraethernet_sim_dbg -u Cmdenv -c MultiHost_64 -f large_scale_test.ini
  ./ultraethernet_sim_dbg -u Cmdenv -c MultiHost_100 -f large_scale_test.ini

  Command Parameters:

  - -u Cmdenv: Use command-line interface
  - -c <CONFIG>: Configuration name from .ini file
  - -f <FILE>: Configuration file to use
  - --sim-time-limit=<TIME>: Set simulation duration (e.g., 10s, 100s)

  The simulation is now ready for scaling to your target of 100s-1000s of nodes with verified end-to-end Ultra
  Ethernet protocol operation!
